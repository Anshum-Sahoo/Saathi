# Carewell

A small, browser-based MVP for an elderly care and medication routine. It helps a person see today's doses, mark doses taken, keep upcoming appointments nearby, and include trusted family members in a demo care circle.

## Run it

Open `index.html` in a modern browser. No install or build step is needed. Data is saved in that browser's local storage.

## What works

- Add, edit, and remove daily medicines.
- Mark a dose taken and see today's progress and a seven-day summary.
- Add and remove upcoming appointments.
- Create a local demo care circle, copy the sample invite code, and toggle demo reminders.
- Responsive layout, keyboard focus styles, and reduced-motion support.

## Scope

This is a frontend demo, not a medical record or reminder service. Passcodes, caregiver sharing across devices, email delivery, and automatic missed-dose detection need a secure backend and are not implemented. The sample family members and invite code are fictional. Do not use this prototype to make medication decisions; follow a clinician's instructions.
